# Responsive Design & Accessibility

The site must feel intentionally designed at every size. Mobile must not feel like a compressed desktop website.

## Breakpoints to check

Large desktop · laptop · tablet · mobile

## Review

Horizontal overflow · typography scaling · spacing · touch targets · navigation · sticky elements · forms · cards · images · videos · animations

## Accessibility (required)

- Semantic markup
- Keyboard navigation
- Visible focus states
- ARIA only where native HTML is insufficient
- Contrast that holds on navy
- Alt text that describes function or content (empty alt for pure decoration)
- Form labels
- `prefers-reduced-motion`
- Accessible interactive controls (menus, buttons, dialogs)

Touch targets should be easy to hit. Sticky nav must not cover headings (`scroll-padding`).

Visual system: `premium-art-direction`. If you cannot use a browser, say what you could not verify.
